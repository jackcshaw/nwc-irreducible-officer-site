# Nameplate definitions (role-neutral)

Jack approved role-neutral one-line definitions for the nameplate on October 28, 2026. They paraphrase the site's Core Failure Modes table ("What goes wrong") without naming a role, so they work with any cast. The site's faculty checks are unchanged.

| Figure | Kicker | Definition |
| --- | --- | --- |
| Frame capture | Failure mode 1 of 7 | The first plausible frame becomes the working frame, unexamined. |
| Fluency substitution | Failure mode 2 of 7 | Polished analysis stands in for owned reasoning. |
| Premature synthesis | Failure mode 3 of 7 | The model connects the material before anyone has built the map. |
| Uncalibrated reliance | Failure mode 4 of 7 | Confident output is accepted without knowing whether the task fits the tool. |
| Invisible delegation | Failure mode 5 of 7 | A request for help hands over criteria, structure, or meaning. |
| Institutional monoculture | Failure mode 6 of 7 | Shared systems and defaults narrow the range of frames a group considers. |
| Responsibility laundering | Failure mode 7 of 7 | The model's recommendation makes agency feel shared, or easier to defend. |
| Appropriate reliance | The skill | Accept AI support where it's warranted, check or refuse it where it isn't, and be able to say why. |
